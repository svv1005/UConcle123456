What Is It?

Photo of the uConsole (add your own picture here)

The uConsole Kit RPI-CM4 Lite is a small handheld Linux computer made by ClockworkPi. It looks like a tiny laptop, but it fits in one hand. Inside it is a Raspberry Pi Compute Module 4 Lite chip, the same kind of chip used in a regular Raspberry Pi 4.

Learn More

Quick Specs

  • Made by: ClockworkPi
  • Chip: Raspberry Pi CM4, 4 cores
  • Screen: 5 inch, 1280 x 720 pixels
  • Keyboard: 74 key backlit keyboard
  • RAM: 4GB
  • Price: About $249

Is It Worth Buying?

It is a good buy if you like building small computer projects and don't mind a learning curve. It is not a good buy if you just want something to replace a normal laptop.
